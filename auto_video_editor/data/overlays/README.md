# Оформление видео: рамка и баннер с тегом

Готовые ассеты для вертикальных версий 1080×1920. Источник (Remotion) лежит в `apps/overlay`, пересобирать его нужно только при смене дизайна или тега. Параметры ассетов описаны в `overlay.json`.

| Ассет | Что это | Куда | Раскладка |
|---|---|---|---|
| `neon` | разделитель: тёмная полоса, неоновые кромки, плашка с тегом | на шов вебка/игра | split (v1, v2, v3) |
| `ticker` | разделитель: бегущая строка `@neuryobank ✦ НЕЙРОБЭНК ✦` | на шов вебка/игра | split |
| `banner` | плашка «Зарабатывай с нами?», выезжает, держится, уезжает (5 с, один раз) | фиксированное место `y=1130` | blur и smart-crop, где вебки и шва нет |

Разделитель — `neon` или `ticker` (какой именно, решает команда), баннер для раскладок без шва нужен в любом случае.

## Форматы

- `*.png` — статичный кадр с прозрачностью. Самый простой вариант, работает везде.
- `*.webm` — анимация, VP9 с альфой, 30 fps, 5 с, 170–365 КБ. Разделители зацикливаются без шва.

**Главное при чтении WebM в ffmpeg.** Встроенный декодер `vp9` теряет альфу: свечение и края рамки становятся сплошной заливкой (проверено). Перед `-i` нужен `-c:v libvpx-vp9`. Полные сборки ffmpeg для Windows (gyan.dev full, BtbN) его обычно содержат; проверка: `ffmpeg -decoders | findstr libvpx`.

## Встраивание в AVE

Положение разделителя по вертикали считается от высоты полосы вебки `split_top` (640 / 680 / 720 в версиях v1 / v2 / v3):

```
y = split_top - height / 2      # neon: split_top - 70, ticker: split_top - 50
```

Дополнительный вход идёт после входов клипа, наложение ставится между раскладкой и хвостом фильтров (`[vlay]` → `[vovr]`), чтобы субтитры (`ass=`) легли поверх рамки. Длину ограничивает `-t` самого рендера, поэтому бесконечный цикл безопасен:

```
-stream_loop -1 -c:v libvpx-vp9 -i neon.webm
...
[vlay][N:v]overlay=0:<y>:shortest=1[vovr]
```

Для баннера петля не нужна: `-c:v libvpx-vp9 -itsoffset 2 -i banner.webm` покажет его один раз со 2-й секунды (`overlay=0:1130`).

Ещё две вещи:

1. **Субтитры v3 стоят под вебкой на `split_top + 40`** (`caption_top_margin` в `render.py`). Полоса разделителя заходит ниже шва на ~47–50 px, так что субтитры наползут на рамку. Для версий с разделителем отступ нужно поднять примерно до `split_top + 70`.
2. **Безопасные зоны TikTok.** Нижние ~340 px и правый край закрывает интерфейс приложения, теги и баннеры туда не ставим.

Проверка наложения без AVE, на любом split-кадре:

```
ffmpeg -loop 1 -framerate 30 -t 6 -i split_base.png -stream_loop -1 -c:v libvpx-vp9 -i neon.webm \
  -filter_complex "[0][1]overlay=0:610:shortest=1,format=yuv420p" test.mp4
```
